# Changelog

Notable project changes are recorded here. No earlier release history was present when this changelog was added.

## 0.1.0 — Initial development release

- Added standalone coordinator and follower MakeCode Python firmware.
- Added elapsed-time phase transitions, start/stop/lights-off controls, packet validation, rolling sequence numbers, acknowledgements, retry limits, status and phase heartbeats, and follower communication timeout handling.
- Added architecture, protocol, wiring, state-machine, safety and development documentation.
- This development release has not been verified on physical micro:bit hardware.
